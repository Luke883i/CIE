## Product invariant preserved

**No object can be declassified as one canonical multiplayer world simply because its `worldId` strings match.** A world is defined by authoritative state identity, transition algebra, resource ledgers, role authority, event history and replay schema together.

AC04's five separate F7 campaigns have the same seeded historical `worldId` but independent state and independent commits. AC03 has one shared AC02 world and a different simulation algebra. The mismatch is intentional and documented.

## Epistemic labels

- `PASS_LOCAL`: actual executable checks passed on selected code and seeds.
- `PASS_STRUCTURAL`: schema, link and manifest checks, not behavior.
- `BLOCKED`: capability absent or unverified on one candidate product.
- `UNOBSERVED`: no independent player population, no remotely deployed real browser E2E.

No previous status automatically promotes a CIE 1.0 global gate. Current release remains `BLOCK` with `0/32` certified.
