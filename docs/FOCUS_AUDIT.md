# Focus Mode · Local adversarial audit

PR scope: presentation/controller only. F7 engine and F10 advanced mode preserved, all new actions are native F7 legal commands.

### 1,000 semantic reflections

Automated 5 roles × 200 seeds, 500 institutional and 500 economic observed states; three available plans per reflection. Each case verifies selection, at most 1 CTA, 3 alternatives, 2 metrics, authorization, view detachment, seed determinism, and sentinel scope nonleakage. Artifact: `proofs/Focus-1000-reflections.jsonl`, summarized in `proofs/Focus-audit.json`. **Semantic probes, not 1,000 independently generated philosophical conclusions or 1,000 human subjects.**

### Independent runtime checks

`npm test`: all existing F1–F10 tests and Focus tests. `npm run audit:focus` runs 1k mixed phase reflections. `python scripts/browser_focus_smoke.py`: Chromium, desktop/mobile, five roles on each, complete episode, replay, inspection does not change F7 digest, no errors. Legacy advanced page remains at `/web/f10-expert.html` and its independent smoke at `scripts/browser_f10_expert_smoke.py`.

### Findings

- Old default was a wide multi-panel dashboard; first-screen mental tasks collided. Focus removes the atlas, V9, finance and diplomacy panels from the initial attention path.
- Initial generic cooperative tagline on an institutional action was misleading; refined to institutional capability-level descriptor and a cautious initial action.
- The old expert view is preserved but not a synchronized browser tab; link accurately labels it **new session**.
- A browser-hosted deterministic single-player game does not protect private state against the browser's owner; focus is observer-level disclosure only.
- No eye tracking, NASA-TLX, SUS, PIX, real-task comprehension, user preference, production hosting or WCAG 2.2 audit was conducted. These are release-gate debt, not hidden successes.
