# RG1 audit · local evidence and boundaries

The role goal layer is **projection only** and does not change the authoritative F7 session, strategy rules, or history. Five missions use only role-specific player commands and observed values; all save/import actions remain F7 replay.

- 1,000 deterministic observer projections across 5 roles and 200 seeds, each with unchanged digest.
- 200 complete campaigns (5 roles × 40 seed variants) and 200 exact replays; all 5 goals reached in sampled games.
- 2,140 legally dispatched human actions inside those campaigns.
- Independent synthetic outcomes: both fulfilled 40; global only 95; personal only 34; neither 31.
- Chromium: ten complete paths (5 roles × 2 viewports), one first CTA visible and import/export replay, no observed JavaScript page errors. Browser uses inlined local source due network restrictions.
- Test suite: see `npm test` log and CI contract `npm run verify:dual`.

**No measured real-player fun, comprehension, emotion, cognition, or sustained engagement.** This is not a public product nor a validated model of European institutions. The source simulator still ends in 8 economic quarters rather than global target of 16. A personal role goal can be reached with globally stalled progress; this is a game dilemma, not a value judgment about officeholders.

Open bugs/debts: actor-choice goals require future player-facing difficulty calibration, meaningful NPC narratives, accessibility with assistive technology, reliable persisted server time, information/security audit, and stakeholder causal calibration. Inlined-browser tests do not prove HTTP deployment.
