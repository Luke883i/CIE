# CIE F8bis · Gameplay First / Bluiette · Normative Contract

**Ruleset** `CIE-F8BIS-1.0.0` · **base commit** `839d8ce57d2f29bfd1f0708445fae3e58b4f79e9` (PR #8 merged) · **status**: runtime UI hardening. **No modification of F7 simulation semantics**.

## Player promise and executable path

1. A player opening `/web/f8.html` sees an unequivocal next-step panel before geography, V9 reference material or bargaining settings: *the current role*, *one goal*, *three named approaches*, *one primary confirmation CTA*.
2. The default **Cooperativo** approach is already selected. The user need not choose counterpart, V9 strategy, economic action or negotiations before the first meaningful action: `requiredPreDecisionInteractions = 0` and `primaryActionCount = 1`.
3. Exactly three labelled options are presented when there is a legal action. Each maps to the existing `f7Play` contract; these are presets, not bonuses. Institutional steps show their **actual named act**, not just a vague risk label.
4. `F7` remains sole authority. Changing options, country, lens, zoom, sidebar settings or opening details is read-only until explicit confirmation.
5. Progress feedback is derived only from `f7Observe` before and after an accepted turn; hidden NPC disposition, bank balance or sealed evidence must never be shown as a prediction. Post-action consequences are framed as *simulated* game facts, not politics in the real world.
6. Expose an opt-in advanced panel, keyboard-operable choices and reduced-motion support; an already-running world is never regenerated by navigation.
7. On judicial `REMEDY` with `irregularity=true`, `ACCEPT_OUTCOME` is not a valid user action despite its legacy presence in raw `available`: present `REQUEST_REHEARING` and `WAIT` only. No bargain over judicial judgments.
8. At end state disable the primary action, preserve replay/export and show a clear closure message.

## Epistemic boundaries

**Valid local proofs:** deterministic code and tested interaction, bounded reachability, DOM geometry of CTA, replay, output files. **Not proven:** actual cognitive load experienced by humans, improvement in enjoyment/retention without external playtesting, screen-reader or full WCAG conformance, real socioeconomic dynamics, 16-quarter game release, 24/7 server persistence. The 100,000 mutation records are **synthetic UI contract scenarios, not 100,000 independently simulated full games**.
