# F10 Audit · falsification and honest evidence boundary

Reproduce `npm run verify:f10` (CI runs 100 reachable campaigns; local full audit 500), `python scripts/browser_f10_smoke.py`. Snapshot original merged PR9 SHA `a4b6915c2a1a7469cfd8ef46c8cc1016dcfe5efa`.

### Probes

1. Action CTA/context: F10 primary hero reuses F8bis, optional advanced tactics closed. 3 options at most.
2. Visibility: 5 SVG stages are keyed to `progress` observable only; 8 quarterly markers have labels, no local geography invented.
3. Privacy: extra injected `privateBalances` and `extrasSecret` must never enter projected experience; 100k checks.
4. Determinism: 100k deterministic model projections and input immutability; replay 500 complete local campaigns.
5. Knowledge: only before/after legal observation is used for receipts; no NPC disposition computed on the client.
6. Browser: 5-role complete decision journeys, terminal, replay import/export, mobile 390px horizontal overflow and primary CTA, Chrome JavaScript error count.
7. Human validation: **NOT RUN**. Player Experience Inventory, perceived cognitive load, dwell time and retention remain evidence debts.

### Known limitations

Simulation still has an eight-quarter economy, not the global 16-quarter campaign. HTML browser smoke embeds static dependencies due local policy; not a hosted HTTP production test. Native screen reader/manual WCAG audit not performed. The staged SVG is authored artwork depicting a symbolic aggregate, not an interactive territorial engine. One cannot infer a game's fun or psychosocial benefits from 100k machine mutations. The games scouted are **references for transfer tests**, not evidence that CIE attains their appeal.
