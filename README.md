# CIE F7 — Strategic Gameplay / Living Europe

An **eight-quarter single-player playable fictional European institutional game** on top of one F3/F4/F5/F6 canonical world. F7 adds repeat-game bargains, conditional coalitions, reputation, trust, counterparty refusals, breaking/fulfilling promises, exits, and judicial independence. Not a complete launch-ready game.

`npm test` / `npm run audit:f7` / `npm run verify:f7` / `python scripts/browser_f7_smoke.py` / `npm run serve` then open **`/web/f7.html`**. All runtime effects and NPC decisions are deterministic and replayable, without generative AI.

F6 remains playable at `/web/f6.html`. F7 does **not** claim server-persistent world time, validated real-world political dynamics or proven human enjoyment. See `docs/F7_CONTRACT.md`, `docs/F7_AUDIT.md` and `docs/TRAJECTORY_T7.md`.
